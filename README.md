# CoWorkHub
Project for INFS4102. CoWorkHub is a desktop application for managing a coworking space.

## Dependencies
* Java 25
* Spring Boot Tools 2.4.1
* Maven 3.10.0

### Spring boot dependencies (for pom.xml)
> [!NOTE]
> There is no need to install anything in this section, it's for documenting the dependencies.
1. Lombok
2. Spring Boot DevTools
3. Spring Data JPA
4. H2 Database

## Building
1. `cd backend/`
2. `mvn clean package`
